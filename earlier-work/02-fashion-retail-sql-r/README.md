# Fashion retail sales analysis (MySQL + R)

**Type:** Project report · **Tools:** MySQL (database design, SQL queries), R
**Report:** [`retail-analysis-report.pdf`](retail-analysis-report.pdf) (84 pages)

## What I did
- Designed an 8-table relational database for a clothing company's sales and revenue, with an EER diagram.
- Wrote SQL to answer business questions on seasonal revenue, payment methods, category performance, customer segmentation by gender, loyalty, purchase frequency, inactive customers, average basket value, best sellers, unique products and sales-channel effectiveness.
- Analyzed the results in R.

## Why it's here
It combines my merchandising background (UNIQLO) with SQL data modeling: schema design first, then business questions.
