# Titanic survival: decision tree (Python)

**Type:** Kaggle notebook (May 2023) · **Tools:** Python (pandas, scikit-learn, graphviz)
**Notebook:** [`titanic-decision-tree.ipynb`](titanic-decision-tree.ipynb) · [Original on Kaggle](https://www.kaggle.com/code/yangle2912/titanic-prediction-decision-tree)
**Data:** Kaggle Titanic competition (public).

## What I did
- Cleaned the data, encoded features, then trained and visualized a decision tree, with 10-fold cross-validation.
- Result: test accuracy 0.693.

## What I'd do differently now
I'd do feature engineering (title, family size), compare against logistic regression and a random forest, and tune tree depth.
